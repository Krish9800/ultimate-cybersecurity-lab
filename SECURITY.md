# Security Policy & Responsible Use Guidelines

## Reporting Security Vulnerabilities

We take the security and integrity of the **Ultimate Cybersecurity Lab** seriously. If you discover a security vulnerability in this project:

1. **Do not open a public issue.**
2. Send a confidential vulnerability report to `security@cyberrange-lab.internal`.
3. Include detailed steps to reproduce, affected versions, and proof-of-concept payloads.
4. We aim to acknowledge reports within 48 hours and provide a remediation plan within 7 calendar days.

---

## Ethical & Educational Cyber Range Charter

The **Ultimate Cybersecurity Lab** is engineered exclusively for:
- Local vulnerability research in isolated testbeds.
- Defensive detection engineering and blue-team verification.
- Educational security curriculum and purple-team exercises.
- Controlled cyber range scenarios on developer-owned systems.

### Strict Prohibitions
- **Zero Targeting of External Systems**: The simulation engines operate using discrete network models and local synthetic test artifacts. Emulation components must never be directed against non-consenting external infrastructure.
- **Harmless Synthetic Payloads**: All attack steps execute benign simulation markers (e.g. proof files, test tokens) rather than destructive payloads.
- **Privacy & Secrets**: No real production credentials, API keys, or private keys are stored or transmitted.
